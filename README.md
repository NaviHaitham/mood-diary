# 心晴 · 情绪日记与自我关怀

一个用于笔试展示的情绪日记与自我关怀网页原型。

**作品地址：[https://navihaitham.github.io/mood-diary/](https://navihaitham.github.io/mood-diary/)**

部署由 GitHub Actions 执行，状态可在 [Actions](https://github.com/NaviHaitham/mood-diary/actions) 查看。提交后请保留账号名、仓库名、访问路径及 Pages 发布设置，使链接保持不变。大陆网络可用性需实际验证。

## 首版功能

- **今天**：多选情绪、强度、事件标签与文字日记，使用 IndexedDB 本地保存。
- **日记**：回看、搜索、按情绪筛选、编辑、确认删除。
- **发现**：近 7 / 30 天趋势、情绪分布、事件标签统计、关怀反馈历史。缺失日期留空，不把强度解释成好坏。
- **关怀**：冥想、雨声音频、轻量活动；按类型、时长、环境筛选，支持计时、暂停、提前结束及体验反馈。
- **隐私与数据**：JSON 导出、校验后合并导入、确认清空个人记录。
- **示例预览**：示例与个人数据隔离，不写入个人记录。
- **响应式界面**：桌面侧边栏、手机底部导航；尊重减少动态效果设置。

## 技术结构

React + TypeScript + Vite，Lucide 本地图标，原生 IndexedDB。

```text
src/
  App.tsx          页面、表单、活动计时及数据交互
  model.ts         数据类型、活动库、趋势、推荐与备份校验
  storage.ts       IndexedDB 事务与持久化
  model.test.ts    统计、校验、推荐和存储测试
  styles.css       桌面与手机样式
  main.tsx         应用入口
.github/workflows/pages.yml   测试、构建与 Pages 自动部署
```

## 本地开发

建议 Node.js 24。首次运行：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认路径为 `/mood-diary/`。

```sh
npm test
npm run build
npm run preview
```

## 部署与更新

GitHub Pages 使用 GitHub Actions 作为发布来源。向 `main` 推送后，工作流依次安装依赖、执行测试、构建并部署到同一个生产地址。`vite.config.ts` 中的 `base` 已配置为 `/mood-diary/`；使用 hash 导航，刷新子页面无需服务端路由。

页面所需代码、图标与样式随站点发布，不依赖第三方公共 CDN、在线字体或外部 API 来完成核心操作。雨声由浏览器 Web Audio 合成，需用户主动播放，不使用未经授权的音乐素材。

## 数据边界

- 日记正文不上传服务器，不需要账户。各浏览器、设备、站点来源的数据相互独立，不支持云同步。
- 浏览器清理数据或无痕会话结束可能导致记录丢失。请定期导出备份；备份包含日记原文，请妥善保管。
- 本地数据未加密，共用设备时请留意隐私。
- 统计及推荐由可解释规则实现，未接入大模型；用户可自行修正事件标签，不提供疾病诊断。
- 关怀练习可随时停止，不承诺治疗效果，不替代专业帮助。
