# 心晴 · 情绪日记与自我关怀

面向笔试的情绪记录与自我关怀产品项目。

## 产品目标

用约 30 秒记录当下情绪，回看可能的触发因素，并选择适合当下的冥想、音乐或轻量活动。

核心流程：记录情绪 → 查看变化与事件标签 → 选择关怀活动 → 记录体验反馈。

## 当前选型方向

计划采用 React + Vite + TypeScript 开发静态网页，IndexedDB 保存访问者的日记；浏览器内完成情绪统计与基于规则的关怀推荐。

使用 GitHub 保存和维护源码，后续可配置 GitHub Pages 自动部署。GitHub Pages 在大陆网络的实际可用性须在提交前验证，不能据此保证所有网络和时段可访问。

方案文档保留此前不同部署路径的比较；当前先建立 GitHub 仓库，最终部署选择以实际验证结果为准。

## 提交要求

最终只提交一个已成功部署、公开且可长期访问的 HTTPS 链接。提交后保持域名与访问路径不变，后续在同一地址持续更新。

## 数据原则

个人日记保存在访问者浏览器中，不提交到公开仓库；不同设备的数据默认不共享。情绪线索采用可由用户纠正的表述，不提供疾病诊断。
